01 // Phase One at a glance

MOC-APPAREL-001

Phase One is six items in one look: solid black blanks with the MOC linear mark in white. Apparel spend stays limited until 2027, so order only what is needed and hold everything else for a later phase.

Blank

Solid black

Jet, washed or garment-dyed black. No heather, gray or other colors.

Mark

Linear // white

Knockout, MOC-BSM-001 1B. White ink or white thread.

Not in Phase One

Everything else

No box logo, isolated curve device, black ink, white blanks, added copy or secondary graphics.

Governing guide

MOC-BSM-001

MOC-BSM-001 wins where the two differ, except the vendor logo and accent color rule in section 04.

Sizing

The actual width is set per item on the placement sheet and approved at proof. Center prints should usually sit well under the 10 in MAX for a high-end fashion read. Size down, never up. The linear mark is close to square (about 1.13 wide to 1 tall), so height is roughly equal to width.

Minimums

0.5 in for print (MOC-BSM-001, unproofed). 1.5 in proposed for embroidery, to be confirmed by sew-out.

04 // Rules

MOC-APPAREL-001

White linear mark, solid black blank, full clearspace, no effects.

Every Phase One item

Blank color

Solid black, including washed and garment-dyed black. The white mark must still read with full contrast. No heather, gray or other colors.

Clearspace

2X the letterform stroke width on all sides. Keep it clear of seams, zippers, plackets, pockets, eyelets and the cap rope.

Off-center hats

The mark stays inside one front panel and never crosses the center seam.

Orientation

Square to the garment, never angled or tilted.

No effects

No distressing, puff, metallic, glitter, outline, shadow or tone-on-tone.

No added copy

Nothing locked to the mark. Phase One carries no other type or graphics.

Official files only

Never redrawn, traced or AI-generated (MOC-BSM-001 section 06).

Vendor logos and accent colors // all phases

When a blank carries a maker's logo (the adidas polo) or an accent color (the rope cap's rope), the MOC mark matches that color and the vendor logo stays out of its way.

Match the color

The MOC mark takes the color of the product's vendor logo or accent. In Phase One that is white throughout: the adidas sleeve logo and the cap rope are both white.

No conflict

The vendor logo sits on a different placement from the MOC mark (for example sleeve versus chest), never inside the MOC clearspace, and smaller than the MOC mark.

Field stays solid

The blank behind the MOC mark is still solid black or solid white.

Exception to MOC-BSM-001

A MOC mark in any color other than black or white breaks the binary rule in MOC-BSM-001 section 05. Each colored case needs design team approval until MOC-BSM-001 is updated to include this rule. REQUIRES APPROVAL

05 // Production

MOC-APPAREL-001

Methods are locked: flat embroidery for the two hats only. DTF (direct to film) or screen print for everything else. The vendor picks DTF or screen print per order, and MOC approves the sample either way.

Official logo files

Download only from the MOC Brand Guide. These are the only approved source files for production.

Download assets

What MOC sends

Vector art (PDF, AI or SVG) built from the official files at final size, one file per placement, single spot color named "MOC White". Plus a placement sheet with the approved width, position from a fixed point (for example, inches below the collar seam) and the blank style number.

File naming

MOC_[ITEM]_[PLACEMENT]_v[##] for example MOC_TEE_CENTERCHEST_v01.pdf

Never accepted

JPG or PNG as production art, logos pulled from the web or social, or redrawn and auto-traced files.

07 // Open items

MOC-APPAREL-001
Decisions needed before the first Phase One order
Q01Quantities and budget

Order count per item and size, and the Phase One spend cap.

Q02Rope cap placement

Pick front center (M2, option A) or off-center (M3, option B) so only one is produced.

Q03Colored MOC marks

Add the color-matching rule to MOC-BSM-001, and decide which color wins when a product's vendor logo and accent color differ.

Q04Thread and ink standard

Name one white thread color number and one white ink spec every vendor matches.

Q05Embroidery minimum

Confirm 1.5 in with a sew-out.

Q06Approver

Name who signs off proofs and samples, plus a backup.
