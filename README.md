# MOC-APPAREL-001: Phase One Apparel Production Guide

Static site for the MOC Phase One apparel spec: items, placements, MAX art sizes, decoration methods, and approval checks.

- `index.html`: the guide (single page, no build step)
- `img/`: mockup images; `img/full/` holds the larger versions used by the enlarge view
- `vercel.json`: Vercel settings

Deploys to Vercel on every push to `main`.

Governing brand guide: MOC-BSM-001 at https://moc-brand-site.vercel.app/
